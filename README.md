# Fashion Apparel Sales – Exploratory Data Analysis

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of a Fashion Apparel Sales dataset using Python. The aim is to analyze clothing sales transactions, understand customer purchasing patterns, handle missing data, and identify sales trends.

## Objectives
- Analyze total revenue across different fashion categories.
- Filter transactions based on apparel size and customer gender.
- Handle missing discount and promotional code values.
- Group sales based on clothing categories and retail store regions.
- Visualize monthly sales trends using line plots.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Google Colab

## Dataset
Fashion Apparel Sales dataset containing clothing transaction and customer-related information.

## Analysis Performed

1. **Revenue Analysis:** Calculated total revenue for different fashion categories using NumPy.
2. **Data Filtering:** Filtered clothing transactions based on apparel size and customer gender.
3. **Missing Value Handling:** Identified and handled missing discount and promotional code values.
4. **Sales Grouping:** Grouped sales data by clothing category and retail store region.
5. **Data Visualization:** Created line plots to understand monthly sales trends.

## Tools and Platform
The analysis was performed using Google Colab.

## Conclusion
This project demonstrates the use of Python libraries for data analysis, data cleaning, filtering, grouping, and visualization. It helps understand fashion retail sales patterns and customer purchasing behavior.
